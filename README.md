# Banker's Algorithm

Implementação do algoritmo de Banker para prevenção de deadlocks, desenvolvida para a atividade de Infraestrutura de Software.

## Compilação

```sh
make
```

## Execução

```sh
./banker 10 5 7
```

O programa lê os arquivos `customer.txt` e `commands.txt` do diretório atual e gera o arquivo `result.txt`.

## Limpeza

```sh
make clean
```
